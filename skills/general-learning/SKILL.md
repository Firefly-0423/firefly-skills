# 通用学习

从用户正在学的内容出发，帮助理解、应用和复习。不预设学科、学历或考试；只处理当前需要的学习环节，不强制创建课程、目录或测验。技能可指导整理题库和试卷，但不会新增面板、存储、判分接口或工具权限。

## 选择当前环节

沿用用户已给的目标、材料、卡点和学习方式，只问会影响下一步的缺口。用户说“直接讲”“不用测验”“从这一节开始”时照办。明确要求系统学习时才组织课程式顺序，沿用宿主既有导学流程，不另造首次学习状态。

| 当前需要 | 按需参考 |
| --- | --- |
| 概念、例题、练习、批改与错因反馈 | `practice-and-feedback.md` |
| 整理题库、组卷、选择题／填空作答及面板适配 | `question-banks-and-papers.md` |
| 笔记、作答记录、续学与复习安排 | `learning-artifacts.md` |

通过宿主 `read_skill_reference` 按清单读取，ref 只填文件名，不带 references/。只读需要的部分，不重复加载所有参考。缺少某工具时说明实际情况，在可用范围用普通对话完成教学。

## 材料与讲解

用户指定材料就先读相关段落，记录实际范围。提取失败、扫描件或内容截断时说明缺口；不能声称读过未访问的文件或知道未给出的考试范围。没有指定材料时可用通用知识解释，例子标为自编，不编造出处。

通常先给直觉或具体例子，再补定义、推导和适用条件。例题按需采用“完整示例→关键步骤补全→变式应用→对照解法”。用户已懂的步骤跳过；不理解时换表示、例子或拆解粒度，不只重复原话。类比要指出边界。

反馈依据实际作答，区分概念误解、条件遗漏、推理跳步、计算失误和表达问题。先指出具体证据，再解释修正办法；不能因“听懂了”或一次答对就宣称长期掌握。

## 练习与作答

用户选择练习时，将题目对应到学习目标与实际材料，先检查题干、选项、答案和评分依据一致。练习、测验和用户要看的答案解析是不同请求，不在自测作答前把答案写进题干、选项提示或说明中。

若本轮刚讲解，先把讲解放在用户可见的最终回复；后续用户选择练习后再调用测验，避免讲解折叠在工具过程里。已明确要求开始测验的轮次可直接出题。

Work 的 `pop_quiz` 当前每批仅 1–3 题，原生支持单选、多选、判断和简答。题库总量可以更大，但不能一次把整卷塞进卡片。题型和字段按当前工具 schema 传递，ID 由宿主生成，不伪造调用成功。

没有原生填空题型时，明确说明可用简答输入作填空练习或在对话中作答；不得声称有分空控件、按空自动判分、完整试卷面板或自动续答。多选沿用宿主全对才判对规则，简答返回 pending_model 后再按评分依据讲评。跳过、取消、未作答和待判分不算答错，也不提前计为答对。

## 保存与续学

只在用户需要且宿主允许时保存实际笔记、题库、试卷或作答记录，不为普通问题批量建空文件。有效 Vault 才使用知识工作区的目录和哈希约定；普通工作区走实际文件工具，没有工作区也可在对话交付。不用其他工具绕过知识工具拒绝。

题库、一次组卷和一次作答分别保留题目版本及记录，后续修改答案不覆盖旧作答的评分依据。没有相应题目版本或记录就标明无法确认，不编造昨天的成绩或学习历史。

学习进度沿用宿主条件：仅已有 learn/progress.md 且允许写入时维护，不为普通笔记初始化，不重建用户删除的文件。复习建议依据可核对的作答；没有已授权提醒能力时不承诺自动通知。

## 交付检查

直接交付用户需要的解释、练习、讲评或实际产物，说明仍卡住的点和合适下一步。区分已讲解、自述理解、本题答对、独立迁移及保存成功。只列实际生成的文件和实际返回的测验结果；文档存在、题目已生成或模拟检查不等于面板验收、用户掌握或考试效果。
