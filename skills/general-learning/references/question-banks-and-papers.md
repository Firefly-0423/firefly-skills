# 题库、试卷与面板适配

本参考指导在用户已有材料和批准工作区中整理练习资料，不新增数据库、原生填空控件、考试引擎或持久化 API。

## 四种记录分开

| 记录 | 内容 |
| --- | --- |
| 题库题目 | 稳定题号、题目版本、知识点、题型、题干与选项、来源、参考答案、评分依据与解析 |
| 一份试卷 | 卷标识／版本、目标与覆盖、所选题目及其版本、顺序、明确给出的评分要求 |
| 一次作答 | 作答标识、卷与题目快照、原始答案、提交／跳过等状态、工具原始结果、讲评及复核情况 |
| 错题复习 | 关联原题版本与作答、具体错因、改正过程和下一次练习建议 |

这些是文档字段约定，不是 pop_quiz 的额外参数。沿用已有题号和目录；新建时给任务内稳定标识，不强制统一命名规则。题目修改后产生新版本，不用新答案覆盖旧作答。版本和评分依据可以由已有记录或用户明确说明确认，已给出的信息不重复追问，不要求先补齐机器字段才能讲评；确实找不到旧版题干、选项或评分依据时，才标明历史成绩无法确认。

原生卡片的 questionId 和选项 ID 由宿主生成，不是永久题库 ID。需要题号对应时可将 `[题库题号@版本]` 作为题干可见前缀，并在实际返回结果后按该批次题序／题目内容保存对应关系；不能臆造 bankQuestionId 等接口字段。

## 组卷与资料保存

用户要求组卷时先确认目标、材料范围、题型与数量；已有要求不重复询问。按材料覆盖和难度需要选题，避免同一道题仅换措辞反复出现。用户要求多少题就在文档中组织相应数量；不要把面板每批上限误当题库或试卷总题量上限。

学习资料适合用已有 Markdown 笔记或表格组织。有效知识工作区中，试卷和配套解析放在 exams/，练习、作答和错题复盘在 exercises/；原始 materials/ 默认只读，templates/ 只在实际存在时引用。普通工作区沿用用户指定结构。没有保存权限就在对话交付，不伪造题库已入库。

自测需要时把题目版与答案解析版分开呈现，作答前不主动展示解析。这是呈现约定，不能保证工作区文件保密或提供监考、防作弊能力。文件中已有答案不代表答案必须出现在作答卡片中。

## 当前 pop_quiz 对接

已核对的宿主每次仅接受 1–3 题。较长试卷在用户选择面板练习时分批，不声称已经一次打开完整试卷。只有实际完成一批、用户愿意继续时才推进；单次工具调用不等于自动续答、全卷提交或持久化成功。

| 学习需求 | 当前原生类型与必要内容 | 边界 |
| --- | --- | --- |
| 单选 | choice；options、correctIndex | 索引从 0 开始，重排选项时同步调整 |
| 多选 | multi；options、correctIndexes | 当前全对才判对；不能宣称原生部分得分 |
| 判断 | true_false；correct | correct 使用布尔值 |
| 简答 | short_answer；referenceAnswer、rubric | 返回 pending_model 后模型讲评，不是本地自动判分 |
| 填空 | 没有原生填空类型；用户接受时以 short_answer 输入编号答案，或对话作答 | 不是分空控件，不传 fill_blank 等未知类型，不承诺按空自动判分 |

所有题目必须提供 question、learningObjective 和 explanation；其他字段以运行时实际 schema 为准。sourceRef 仅引用确实通过知识工具读过的 Vault 材料，包含 file 和可选 heading；没有此类来源时不编造路径。

例如下面是自编的单选数学练习输入，不宣称来自用户教材，也不是已执行调用：

```json
{"questions":[{"type":"choice","question":"[CALC-Q001@1] f(x)=x²，在x=2处的导数是多少？","options":["2","4","6","8"],"correctIndex":1,"learningObjective":"求多项式函数在一点的导数","explanation":"f′(x)=2x，因此f′(2)=4。"}]}
```

填空替代练习可将“f′(x)=___，f′(2)=___”标为简答输入，提供 referenceAnswer 与 rubric，并要求按空号书写。接受等价表达与数值条件在评分依据里说明，提交后模型讲评。不得将这种练习描述为宿主新增了原生填空面板。

## 恢复与汇总

恢复练习时先读取已保存且获准访问的试卷、题目版本、作答和当前进度。只有对话记忆而无记录时说明无法确认，不凭空恢复“第几题”或成绩。工具卡片可能已结算或取消，不假装仍能操作旧卡片。

全卷汇总按实际已判题目报告分子、分母与范围；待判、跳过、未作答和取消分别列出。部分批次完成不能宣称全卷已交。改正答案和复核建议单独记录，保留原始作答与工具判分。
