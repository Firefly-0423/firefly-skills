# 教程 Notebook

由 OpenAI tutorial-patterns.md 改编；Firefly 版保留用户节奏并明确演示与练习状态。

开头说明读者、前置知识、目标和简短目录。用户已经给出背景时直接沿用，不重复采访或强制测试。

每个阶段使用简短解释、小代码单元与结果解读。单元可以依赖前面的明确初始化，不能依赖前次会话或跳过执行的隐藏状态。用最小、可检查的例子展示概念，再指出使用条件和常见错误。

用户希望练习时，可给补全步骤、变式任务或一个独立应用题；答案解析与练习目的区分。用户只需要完整讲解或演示时，直接交付，不强制留空代码或测验。

练习中故意留空的代码明确标为未完成，不在“全部执行成功”的声明里悄悄排除。若有解答版和练习版，分别说明检查与运行范围；练习版未完成的单元不能冒充已运行。

说明一种常见误解及修正办法，按需要给一个可选扩展。用户作答、读者测试或教学反馈未发生时，不声称学会、掌握或通过验收。

例子可以使用自编数据，但要标明，不冒充用户提供的测量或教材原文。需要网络、额外包或数据下载时提前说明条件，不让教程第一次运行就暗中安装或外传内容。
