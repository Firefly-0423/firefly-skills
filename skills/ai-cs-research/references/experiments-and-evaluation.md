# 计算实验与 AI 评估

只有用户要求设计、分析或执行相关实验时读取相应部分。读取本参考不授权命令执行、安装、下载、费用、数据上传或长期任务。

## 先把主张变成实验

每个必要实验说明：检验的主张、替代解释、数据与划分、比较对象、主指标、关键配置、支持条件、失败解释和停止条件。先区分必须执行与可选扩展，避免没有决定价值的消融清单。

常见替代解释包括更大模型、更多训练数据、更长预算、不同提示词、额外检索、测试泄漏或指标口径改变。基线与候选条件不同就报告不可比之处，而不是按数字直接排序。

先检查现有项目的代码、环境说明、输入和资源。缺失条件不影响只读分析；若需要增加安装、下载或远程资源，先提出有范围和成本依据的方案，由宿主和用户已有授权决定下一步。不得为模拟结果伪造成功状态。

## 研究类型

| 类型 | 关键核对 |
| --- | --- |
| 机器学习 | 数据版本、预处理、标签、划分、初始化、选模规则、训练预算、最终测试是否独立 |
| LLM／微调 | 模型／检查点及已披露版本、训练与示例来源、提示词、采样、上下文与推理预算；未知信息保留未知 |
| RAG | 语料快照、切片、索引、召回／重排、生成模型与提示词；分别考察检索、依据与端到端表现 |
| Agent | 任务与环境初始状态、可用工具、完成判据、错误、重试、交互预算、耗时与成本；重复实验需恢复相应初始状态 |
| 算法／系统 | 命题前提与复杂度；工作负载、硬件、软件、并发、预热／缓存、吞吐与延迟口径及资源代价 |

不必填满无关类型。RAG 同时换了生成模型和检索器时，不能把提升都归因于检索创新；Agent 声称完成要检查实际目标产物或状态，不能只读它的自然语言答复。

## 执行与留证

在批准的工作区和既有授权范围执行。优先最小可运行基线，然后关键候选和对照。固定评价方式后再看结果；若结果导致修改假设或指标，将其标记为探索性分析。

每次实际运行记录或明确缺失：输入及数据版本、代码版本或当前改动、配置与依赖、硬件、命令、退出／超时／取消状态、日志及原始指标、产物位置、资源消耗和限制。已有项目沿用其记录方式；不因本模板强制提交 Git 或创建空目录。

Notebook 能执行时从干净状态自上而下运行，避免依赖交互残留。不能执行时交付可审阅草案与缺口，写“未执行”。仅部分步骤完成时逐项说明，文件生成或退出码成功不自动代表训练、评估或复现成功。

训练、验证与最终测试各有职责。最终测试不作常规选模；若已反复按最终测试选择方案，披露自适应选择影响，不能仍声称独立保留集验证。

## 评分与统计

指标对应当前任务与实际样本范围。真实标签、人工标签、合成代理、被测模型自己生成的答案、其他模型裁判分别注明。检查指标计算和归一化含义，不能以自生成参考的高一致率冒充真实准确率。

模型裁判记录设置、评价标准、参考答案来源、顺序偏差控制与人工校准状态。没有校准记录则说明未校准；自动评价不等于真实用户验收。

重复次数、种子、区间和统计方法按数据单位、前提与资源选择。报告实际次数与变异来源，保留适用的效应量、区间和多比较处理。单次结果不补造误差条、置信区间或稳定性；不只展示最佳分数，相关负结果和失败实验保留。

## 状态与下一步

区分未执行、尝试失败、冒烟通过、目标实验完成、与参考结果完成可比核对。说明复现了哪些数据、设置与指标，以及哪些差异尚未解释。小样本跑通不意味着泛化或论文主张成立。

到达用户指定预算、停止条件或任务范围后交付当前证据。独立复核只在实际能力与授权允许时安排；自查、独立代理、跨模型审阅和科研用户验收分别报告，不自行注册循环或联系外部服务。
